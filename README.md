# திருக்குறள் 467 | Thirukkural 467 — Think Before You Act

An interactive, 3D educational web experience based on **Thirukkural No. 467**:

> **எண்ணித் துணிக கருமம்; துணிந்தபின்**  
> **எண்ணுவம் என்பது இழுக்கு.**  
>  
> *"Think carefully before taking action. Once a decision has been made after proper thinking, act confidently without unnecessary hesitation."*

---

## 🌟 Concept: "Think → Decide → Act"

The website is designed around the core law of deliberate action:

```text
Situation ➔ Think ➔ Analyze Consequences ➔ Make Decision ➔ Act Confidently
```

**"Think before you act — not after."**

---

## ✨ Features

- **🏛 3D Hero Section:** Sculpted Tamil typography, audio pronunciation recital via Web Speech API, and the core formula capsule (`THINK ➔ DECIDE ➔ ACT`).
- **📖 Understand the Kural (Wisdom Anatomy):**
  - **Part 1:** *எண்ணித் துணிக கருமம்* (Evaluate all dimensions, consequences, and resources before starting).
  - **Part 2:** *துணிந்தபின் எண்ணுவம் என்பது இழுக்கு* (Once committed, second-guessing leads to weakness and failure).
- **🎮 "What Would You Do?" Interactive Decision Game:** 4 real-life dilemmas (Student life, Personal finance, Career crossroads, Digital discourse) with custom scenario illustrations and dynamic evaluation feedback (Impulsive vs. Kural 467 vs. Overthinking).
- **🧭 Decision Simulator ("Before You Decide..."):** Step-by-step guidance for real-world choices (Benefits, Risks, Alternatives, Consequences) ending with an unrolling 3D sealed parchment pledge.
- **⚖️ Think vs. React Comparison:** Side-by-side illustrated paths comparing the *Impulsive Spiral* vs. the *Valluvar Framework*.
- **⚡ 10-Second Decision Challenge:** High-stakes trial measuring response time to teach the balance between hasty reactivity and paralyzing overthinking.
- **🌍 Modern-Day Applications:** Practical cards covering Education, Career, Money, Relationships, Technology, and Leadership.
- **🎵 Web Audio Synthesizer:** Pure mathematical sound synthesis (temple singing bowls, wooden clicks, caution tones) without external audio dependencies.
- **🎨 Dual Theme System:** Seamlessly toggle between *Warm Manuscript Parchment* and *Dravidian Obsidian Night*.

## 🛠 Technology Stack

Strictly zero external dependencies or frameworks:
- **HTML5** (Semantic structure & ARIA accessibility)
- **CSS3** (3D transforms, perspective, flexbox/grid, animations)
- **Vanilla JavaScript** (Game logic, Web Audio API, Speech Synthesis, IntersectionObserver)

## 🚀 How to Run

Simply clone the repository and open `index.html` in any web browser:

```bash
git clone https://github.com/nandhakumar3663-afk/kural-467.git
cd kural-467
```

Then open `index.html` directly in your browser:

```bash
# On Linux
xdg-open index.html

# On macOS
open index.html

# Or run a simple local server
python3 -m http.server 8080
```
